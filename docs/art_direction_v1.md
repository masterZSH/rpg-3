## 1. 美术方向（10 行）

1. **基调**：东方志怪 · 夜行——「墨底、纸白、朱红一点」。以反差极大的**剪影**叙事：所有单位先是可读的黑影轮廓，再谈细节；拒绝日式赛璐璐与欧美厚涂。
2. **主色（夜色底）**：`#0B0E14` 最深底 → `#12161F` 战场底 → `#1A1F2B` 剪影/墨块 → `#2A3140` 结构线。**画面 70% 面积必须是这四档暗色之一**。
3. **纸白（前景）**：`#E8E3D7` 纸灰白作主体亮面，`#F5F0E4` 作最高光（伤害数字、暴击、UI 文字）。暗底 + 纸白 = 天然高对比，保证小屏可读。
4. **点缀色（严格限量，同屏 ≤2 种）**：朱红 `#C8362B`（危险、预警、Boss）、金 `#E8C46A`（暴击、升级、拾取、成功闪避）、青焰 `#4FA8D8`（术士/灵力）、翠 `#6FBF73`（游侠/治疗）、橙红 `#E8734A`（力士/怒气）。**点缀总覆盖面积 < 15%**。
5. **线条**：单一粗细、无渐变描边的「毛笔硬边」——外轮廓 3px `#0B0E14` 压边，内部 1px `#2A3140` 结构线；禁止羽化、禁止多重外发光（省低端机 GPU）。
6. **形状语言**：修长竖向（人）、横向压扁（伏地妖）、尖锐不规则三角（凶妖）、浑圆对称（Boss 与法器）。一切几何化：圆/胶囊/梯形/折线，**阶段2 全部能用 Canvas 路径画出来**。
7. **质感（阶段3 才做）**：宣纸颗粒（`noise` alpha 0.04）、墨晕边缘（2px 内缩半透明）、朱砂印章方点。阶段2 一律平涂，不加质感。
8. **字体 · 中文（无外链）**：不引任何 Web Font，用系统本地字体栈，靠字重 + 字距拉开层级。
   `--font-cn: "PingFang SC","Hiragino Sans GB","Source Han Sans SC","Noto Sans CJK SC","Microsoft YaHei","Heiti SC","WenQuanYi Micro Hei",sans-serif;`
   `--font-num: ui-monospace,"SF Mono",Menlo,Consolas,"Roboto Mono",monospace;`（伤害数字、CD 秒数、伤害/血量数值必用等宽，防跳动）
9. **字体层级（390 宽下不许更小）**：正文 14 / HUD 标签 12（仅大写英文与数字）/ 按钮主文案 16 / 伤害数字 20（暴击 28）/ 章节标题 24。**最小字号 12，且必须配 `#F5F0E4` 或 `#E8C46A`**。禁止细字重（<400）在暗底使用。
10. **动效性格**：短、硬、有重量——命中 2–3 tick 内完成，位移用 `ease-out`，拒绝弹性回弹与长时间渐入；屏幕震动 ≤4px 常规 / ≤10px Boss 死亡（沿用 §9）。

## 3. 验收点（3 条 · 他人可肉眼或简单比对确认）

1. **对比度**：取色器点「角色/杂兵主体填充色」与其紧邻背景，换算灰度明度，比值 **≥ 4.5:1**；伤害数字 `#F5F0E4` 对战场底 `#12161F` **≥ 12:1**。真机 390×844、约 30cm 距离，最小单位（杂兵 28×40、敌人血条 60×5）可一眼定位。
2. **零外链自足**：断网 + `file://` 打开，画面无缺图、无缺字、无豆腐块；DevTools Network 中**外部域名请求数 = 0**。同屏点缀色（朱红/金/青/翠/橙红）不超过 2 种，暗色四档占面积 ≥70%（截图后用取色统计粗估即可）。
3. **不遮挡**：战场有效区 **y 96–570** 内，任意时刻被 HUD、预警横幅、底部面板**永久遮挡的面积 ≤ 5%**；伤害数字上飘全过程中不越过 y=96、不被底部按钮区裁切；底部五个热区（药瓶/闪避/技能ABC）实测 ≥44×44 且两两中心距符合 §8.1。

| Boss 机制横幅（y=100,32px 高） | `#C8362B` alpha 0.30 | 上下 1px `#C8362B` | 仅 Boss 战出现；文字 `#F5F0E4` 16px；按 §8.2 计入 ≤3.8% 高度 |
| **伤害数字层** | 无底 | 3px `#0B0E14` **必填**（深色/浅色背景都靠它分离） | 上飘起点受击者头顶 +26px，终点不越过 y=96；同屏上限 12，重叠上移 22px（§8.2） |
| 敌人血条（头顶 60×5） | 槽 `#0B0E14` alpha 0.85 | 1px `#0B0E14` | 填充 `#C8362B`；杂兵不画（§8.2） |

**深色背景上的数字/文字硬规则（全项目通用）**
- 任何叠在战场上的文字，必须有 **3px `#0B0E14` 描边**（`ctx.lineWidth=3; ctx.strokeText` 先描后填），这是唯一保证在深浅背景交界处仍清晰的手段。
- 禁止在战场上使用 alpha > 0.85 的纯色大色块做提示；预警一律「填充 alpha 0.30 + 3px 描边」（§8.2 已定）。
- 暗底细线统一 `#2A3140`；`#000` 与 `#fff` 全项目禁用（前者压死层次，后者刺眼）。
