## 0. 基调一句话

延续「墨底、纸白、朱红一点」：正式美术不改变剪影原则，而是把"几何色块"升级为**有轮廓性格的剪影**——每个单位 = 墨色主体 + 3px 墨边 + 1 笔纸白高光 + 1 处职业/阵营点缀色；场景从"一层渐变"升级为**三层视差 + 三种氛围动效**；UI 从"纯色块"升级为**分层次结构**（底/填充/高光/残影/描边）。暗色四档（`#0B0E14/#12161F/#1A1F2B/#2A3140`）仍占画面 ≥70%，点缀色同屏 ≤2 种、总面积 <15% 的规则全文有效。

**色板 v2（在 `src/data/balance.js` 的 `theme` 上追加，data 层改动，不触碰 core）**：

```js
// 追加项（沿用现有键不动）
```

## 1. 三职业主角造型（Canvas path 级 · 44×72 逻辑档）

统一规则（三职业共用）：
- 主体填充 `#1A1F2B`（墨），外轮廓 3px `#0B0E14` 压边；**职业色不再整体平涂躯干**，改做披风/腰带/武器脊一点缀（同屏点缀 ≤2 种因此达标）。
- 高光层：每单位**恰好 1 笔**纸白 `#E8E3D7`（宽 2–3px 短弧/短线），置于左上受光侧。
- 衣纹：躯干内部 1px `#2A3140` 结构线 1–2 条，禁止超过 2 条（省 fill/stroke 次数）。
- 待机呼吸：整体 y ±1.5px 正弦，周期 60 tick（`Math.sin(stateTick*2π/60)`，渲染层可读 tick/自行累计 dt，**不读墙钟**）。
- 行走/攻击姿态帧不做（特效层叠加上表达，见 vfx 规格）；仅保留 facing 翻转（现有 `ctx.scale(-1,1)`）。

## 2. 18 妖 · 6 模板 × 参数（+3 Boss 独立造型）

统一规则：
- **渲染层内置造型映射**：`worldRenderer` 顶部 `const MONSTER_ART = { zhiren: 'M1', ... , tint: {...} }`（或把 `art` 字段加进 `src/data/monsters.js`——data 层允许，二选一，主程序定）。按 `e.id` 取模板号与参数，`core` 不感知。
- 妖主体仍是**暗于玩家的剪影**：主色比玩家深半档，描边 1.5px（精英 2px / Boss 3px），红眼保留为唯一"危险信号"（杂兵 5px 方、精英 6px、Boss 8px，颜色 `#C8362B`）。
- 每模板给 1 笔高光 + 模板级配色；个体差异靠**参数行**（不改 path 骨架，只改数值/开闭），保证 18 只不撞脸但不新增 path 成本。
- 模板尺寸沿用现有三档几何基座（small 圆 r16 / medium 28×40 / large 40×52），造型在基座上"加件"而非重画。

### M1 纸身人形 —— 纸人 / 无面僧 / 咒偶
构成（4 行）：① 竖长纸片躯干：medium 基座上画竖矩形 18×34，底边剪成 2–3 个锯齿断口（纸撕裂感）；② 头：r=7 圆上叠一张 8×10 符纸（纸白，1px 朱符纹）；③ 双臂：两条 2px 下垂墨线，袖口外翻小三角；④ 1px 竖向折痕 1 条贯穿躯干。
- 主 `#1A1F2B` / 辅 `#C8362B`（符纸纹与眼同源）/ 描边 `#E8E3D7` alpha .35（纸边发白是本模板特征）/ 高光 `#E8E3D7`（符纸面）
- 参数：纸人=断口 2、无臂饰；无面僧=断口 3、加念珠（胸前 1px 弧线+3 个 2px 点）、符纸留白无纹；咒偶=断口 2、躯干加 2px 十字缝线、眼距加宽

### M2 悬浮灵体 —— 灯笼鬼 / 狐火 / 血蝠
构成：① 主体：椭圆/圆球（small 基座 r14）；② 下摆火须：3–4 条向下的三角火舌（path：底边中点下垂折线）；③ 悬浮 bob：y ±3px 正弦（周期 40 tick，相位按 e.id 哈希错开）；④ 内芯：中心小圆做"灯芯"，主色暗、内芯亮。
- 主 `#1A1F2B` / 辅（内芯+须尖）按个体 / 描边 `#0B0E14` / 高光 `#E8E3D7`（球体左上 1 弧）
- 参数：灯笼鬼=内芯 `#E8734A`、须 4 条、球体加 2px 上下横箍线（灯笼骨架）；狐火=内芯 `#4FA8D8` 青焰、须 3 条拖尾更长；血蝠=内芯 `#C8362B`、加收拢双翼（两侧各 1 片 12×8 折线翼膜，随 bob 开合 ±4px）

### M3 低伏兽形 —— 水猴 / 鬼面蛛 / 蚀骨蜈
构成：① 低伏身体：横向压扁胶囊（长 34×高 18），贴地；② 头部：前伸小圆 r=7 + 吻部尖角；③ 腿：2px 墨线折线（数量=参数）；④ 尾：1 条 2px 上翘折线。
- 主 `#1A1F2B` / 辅 `#2A3140`（背脊条带 2px）/ 描边 `#0B0E14` / 高光 `#E8E3D7`（背脊最高点 1 短线）
- 参数：水猴=腿 2（蹲姿）、尾长 14 带水珠点；鬼面蛛=腿 8（两侧各 4，弧线下垂）、加 8×8 纸白"鬼面"贴头（2px 朱纹）；蚀骨蜈=改多节（3 节相连胶囊，节间 1px 缝），腿每节 2 根、共 12，改 large 基座

### M4 枝条蔓生 —— 竹影 / 藤妖

### M5 翼形飞禽 —— 骨雀 / 夜枭 / 檐鬼（精英）

- 主 `#1A1F2B` / 辅 `#2A3140`（翅第二段降档色）/ 描边 `#0B0E14` / 高光 `#E8E3D7`（头弧 1 笔）
- 参数：骨雀=翅小（12px）、飞行 bob 快（周期 24 tick）；夜枭=翅大（20px）圆头加 2 只耳羽三角；檐鬼=**翼收拢贴背**（改为 2 条背脊折线）+ 2 只前伸钩爪（2px 折线）+ 头顶斗笠三角 14×6，尺寸升 large 基座，精英描边 2px

## 4. UI 质感（全部现有矩形内做层，不动 §8.1）

### 4.1 技能键（药瓶/技能 A/B/C/闪避统一规格）
分层（DOM 结构不变，靠 CSS 伪元素加层）：
1. **底**：`background: linear-gradient(180deg, #1E2530 0%, #1A1F2B 60%, #141922 100%)`（上下微渐变替代平涂，零成本立体感）；
2. **内阴影**：`box-shadow: inset 0 3px 6px rgba(0,0,0,.55), inset 0 -1px 0 rgba(232,227,215,.06)`（上暗下亮一线）；
3. **金属描边**：现有 2px `--ink3` 之上，`::before` 叠 `border: 1px solid rgba(232,227,215,.10); inset: 2px; border-radius: 10px`（双线框=金属感）；
4. **CD 扇形**：沿用 conic-gradient，但遮罩色改为 `conic-gradient(rgba(11,14,20,.85) Ndeg, rgba(11,14,20,.45) N+40deg, transparent N+40deg)`——扇形扫过边缘带 40° 渐变尾（纯 CSS，无 JS 改动，`hud.js` 的 `maskStyle` 换此模板即可）；
5. **按下反馈**：现有 `scale(.93)` 保留，追加 `box-shadow` 切换为全内阴影 `inset 0 0 10px rgba(0,0,0,.8)`（下沉感）；
6. **就绪态**：描边换职业点缀色（现有 `.ready` 机制），追加图标层 `opacity` 呼吸 0.75↔1（1.2s ease-in-out infinite，仅 1 个元素，开销可忽略；低端档关）；
7. **闪避键**：同规格，双线框 alpha 提到 .18、按下 scale(.96)（主操作键更沉稳，不漂）。

### 4.2 血条 / 资源条 / 经验条（顶栏，矩形不动）
- **底槽**：`rgba(11,14,20,.9)` + `box-shadow: inset 0 2px 4px rgba(0,0,0,.7)`（凹槽感）；
- **HP 填充**：`linear-gradient(180deg, #E8734A 0%, #C8362B 55%, #9C2A22 100%)`（上亮下暗的体积感，符合 art v1 §2 渐变许可）；填充层上 `::after` 叠一道斜高光：`linear-gradient(115deg, transparent 40%, rgba(245,240,228,.16) 50%, transparent 60%)`；
- **损耗残影**：fill 之下加第二层 `.ghost`（同尺寸），同吃 `scaleX` 但 `transition: transform .5s ease-out .35s`（延迟 0.35s 慢追），色 `rgba(232,227,215,.35)`——掉血时白影短暂留在损耗区再被吞掉。`hud.js` 需为 hpFill 旁插入 1 个 ghost div（顶栏矩形内加层，非新增 HUD 元素）；
- **描边**：槽外框 1px `#2A3140` + 顶部 1px `rgba(232,227,215,.12)` 内亮线；
- **低血呼吸**（<30%）：HP 槽叠一层朱红 overlay，`animation: hpPulse .5s step-end infinite alternate`（opacity .15↔.4，对应 art v1 "6 tick 呼吸"），低端档关；

- **经验条**：不动（8px 高度，保持低调是设计意图）。

### 4.3 面板卡片（职业选择/三选一/暂停/结算共用 `.classCard`/`.rewardCard`/`.panelList .item`）
- **纸纹理**：底色 `#12161F` 上叠 `background-image: repeating-linear-gradient(0deg, rgba(232,227,215,.022) 0 1px, transparent 1px 3px), repeating-linear-gradient(90deg, rgba(11,14,20,.05) 0 1px, transparent 1px 4px)`（两组正交细纹=宣纸纤维，纯 CSS 零请求；低端档回退纯色）；
- **墨晕边**：`box-shadow: 0 0 0 1px #2A3140, inset 0 0 14px rgba(11,14,20,.5)`（内圈暗晕，边缘像墨渗进纸）；
- **边框纹样——朱砂角印**：`::before/::after` 各画 2 个角（`width:8px;height:8px;border-left:2px solid #C8362B;border-top:2px solid #C8362B` 定位左上 / 右下），共 4 角对角呼应；选中态（`.selected`）角印换 `#E8C46A` 并加宽到 3px；
- **标题条**：面板 `.title` 下加 24px 宽 2px 朱红短线居中（印章式落款）。

### 4.4 伤害数字（Canvas 层，`drawFloaters` 升级）
- 基础：`bold 20px font-num` + 3px `#0B0E14` 描边先描后填（不变，§8.2 红线）；
- **暴击**：28px + `#E8C46A` 填 + `#7A2E22` 3px 描边 + 缩放脉冲 1.0→1.25→1.0（现有实现保留）+ **新增朱砂印**：数字右上角叠 4×4px `#C8362B` 方块（旋转 12°），随文字同生命周期；
- **飘动曲线升级**（替换现有纯竖直上飘）：
  - 竖直：`y = y0 − 40 × easeOutQuad(t)`，其中 `easeOutQuad(u) = 1 − (1−u)²`（前快后缓，t 为剩余寿命比 1→0）；
  - 横漂：`x = x0 + sin((1−t) × π) × 6 × drift`，drift=+1/−1 由 e.x 奇偶决定（免费伪随机，不引随机源）；
  - 淡出：alpha = `min(1, t × 2.2)`（现有），前 70% 寿命完全不透明；
  - 暴击额外屏停感：暴击字 floaters 寿命 ×1.25（18→22 tick，仍在 §8.2 上飘 40px 框架内，起终点不变）；
- 治疗 `#7FD48A` / 承伤 `#FF6B5E` / 灼烧 `#E8734A` 沿用；同屏上限、重叠上移 22px、上飘不越 y=96 全部不变。

## 8. 验收点（5 条，肉眼/取色可判）

1. **剪影可辨**：任取一只杂兵与玩家同框截图，剪影轮廓清晰，且每个单位可数出「主色填充 + 描边 + 1 笔高光」三层明度；主体填充与紧邻背景灰度明度差 ≥2 档（取色器粗估）。18 妖两两同框不混淆（同模板靠参数差异可分）。

3. **场景分层成立**：三章背景色调肉眼可分（冷青 / 墨绿 / 暖紫）；战斗中平移可见远山与近景错位（≥2 层视差），且雾漂移 / 尘埃上浮 / 光斑呼吸至少其一动效肉眼可见。
