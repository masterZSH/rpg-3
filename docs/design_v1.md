## 1. 一句话卖点 + 三句话体验

**卖点**：一只拇指就能打完的东方志怪实时 Roguelite——你只管在刀锋落下的那一瞬间按下闪避。

**玩起来什么感觉**：

1. 你在荒村的灯笼下站着，妖物一只接一只从夜色里浮出来，你的角色自己抬刀就砍，刀刀带风、血花溅在屏幕上；你要做的不是操作走位，而是盯着那圈突然亮起的红光，在它炸开的瞬间点一下闪避——擦身而过的半秒钟，是整个游戏最爽的半秒。
2. 打完一拨，地上掉出一把"灵·精钢刀"，屏幕直接弹出对比：攻 +9、附带破甲。你一点替换，下一场的刀声立刻变沉、变狠。三选一又掏出"技能升级"，你的斩击从此带破甲，手感从"砍"变成"劈开"。
3. 一路砍到章末，鼓声响起，Boss 抬起手——你知道那一下躲不掉就是半条命。躲过去，反击，血线见底，灌下最后一瓶药，把它按死在灯笼里。十二分钟，一局，死在第三章就重来，但这一局掉落的道行已经替你把"游侠"解锁了。

## 3. 实时战斗操作映射（核心）

### 3.1 为什么没有摇杆（覆盖技术基线 5.7）

硬约束②是"单手点击、不做虚拟摇杆/拖拽"。因此**玩家的位移不是玩家的操作，而是系统的行为**：

- 玩家角色**自动**朝"当前锁定目标"移动，稳定停在 `攻击距离 × 0.9` 处；目标死亡立刻自动锁定下一个最近敌人。
- 玩家唯一可控的位移是**闪避**（一次点击，位移 110px，方向由系统计算，见 §3.5）。
- 敌人的接近、包围、后撤全由敌人 AI 完成，玩家不需要、也无法用走位拉扯。

**理由**：摇杆需要持续按住 + 微操，与"单手 30–90 秒不累"直接冲突；而"自动寻敌 + 一键闪避"把玩家的全部注意力压缩到一个决策上——**这一下要不要躲**。这也让"实时战斗"的紧张感从"操作量"转移到"判断量"，是竖屏单手唯一成立的解法。

### 3.2 每一帧里，系统在自动做什么

固定步长 30Hz 逻辑 tick，每 tick 顺序执行：

| # | 系统行为 | 说明 |
| --- | --- | --- |
| 1 | 资源再生 | 术士灵力 +9/s；力士/游侠脱战衰减判定；耐力回复（闪避结束 12t 后开始，+15/s） |
| 2 | Buff/DeBuff 计时 | 剩余 tick −1；到 0 移除；灼烧每满 30 tick 结算一次 |
| 3 | 冷却递减 | 3 个技能 CD、闪避 CD、药瓶 CD 各 −1 tick |
| 4 | 输入缓冲裁决 | 若某技能处于缓冲窗口（CD 剩余 ≤ 9 tick）且已缓冲，则 CD 归零 tick 立即释放 |
| 5 | 敌人 AI | 接近 / 攻击前摇 / 释放技能 / 机制预警推进 |
| 6 | 玩家自动移动 | 向锁定目标移动到 `range × 0.9`，速度 = SPEED × (1 − 缓滞) |
| 7 | 普攻判定 | 距上一次普攻 ≥ `INTERVAL_TICKS` 且目标在射程内 → 进入 attack 状态 |
| 8 | 弹道推进 | 术士普攻弹速 420 px/s；技能弹道按各自速度 |
| 9 | 命中结算 | 伤害公式 §5.1 → 护盾 → 生命 → 死亡判定 |
| 10 | 波次推进 | 本波全灭 → 36 tick 后下一波入场 |

### 3.3 玩家点了什么，会发生什么

| 玩家操作 | 响应时机 | 结果 |
| --- | --- | --- |
| **点技能键** | `pointerdown` **按下即触发**（不等抬起，不等冷却） | ① 冷却中且剩余 > 9 tick → 按钮灰 + 抖动 0.12s + 短促"哒"声，**不入队、不缓冲**；② 冷却中且剩余 ≤ 9 tick → 进入缓冲，CD 归零时自动释放；③ 可释放 → 立即进入 cast，施法结束出伤 |
| **点闪避键** | `pointerdown` 按下即触发 | 耐力 ≥ 30 且闪避 CD = 0 且不在 hurt/dead → 进入 dodge（§3.5）。耐力不足或 CD 中 → 按钮闪红，无位移 |
| **点药瓶键** | `pointerdown` 按下即触发 | 数量 > 0 且药瓶 CD = 0 → 立即回复 30% 最大生命，数量 −1，进入 300 tick 共享 CD |
| **点暂停** | `pointerup` 抬起触发 | 逻辑暂停，弹暂停面板 |

**为什么用 `pointerdown` 而不是 `pointerup`**：移动端 `click` 有最高 ~300ms 的确认延迟，而本作闪避无敌帧只有 14 tick（0.467s），300ms 会吃掉 2/3 的窗口，等于机制不可躲。Pointer Events + `touch-action:none` 下 `pointerdown` 无延迟（`tech_baseline_v1.md` 5.6 已定）。UI 类按钮（暂停、三选一）仍用 `pointerup` + 12px 位移阈值，避免误触。

### 3.4 普攻节奏与技能 CD 显示

| 职业 | 普攻间隔（tick / 秒） | 普攻系数 | 攻击距离 | 弹道 |
| --- | --- | --- | --- | --- |
| 力士 | 33 t / 1.100 s | 120% ATK | 70 px | 无（即时判定） |
| 术士 | 32 t / 1.067 s | 85% ATK | 265 px | 有，420 px/s |
| 游侠 | 18 t / 0.600 s | 52% ATK | 155 px | 无（即时判定） |

实际间隔 `INTERVAL_TICKS = max(6, round(BASE_INTERVAL_TICKS × 100 / (100 + HASTE)))`

**CD 显示**：不占额外空间——CD 转圈画在**技能按钮内部**，用 `conic-gradient` 扇形遮罩从 12 点顺时针扫过；按钮中心叠一行数字，仅当剩余 CD ≥ 45 tick（1.5s）时显示，字号 16px，剩余 < 1.5s 时隐藏数字只留扇形（避免小屏数字跳动干扰）。

### 3.5 闪避（本作的核心操作，参数全在这里）

| 参数 | 值 |
| --- | --- |
| 触发条件 | 耐力 ≥ 30 且闪避 CD = 0 且状态 ∈ {idle, attack, cast} |
| 总时长 | 17 tick（0.567 s） |
| **无敌帧** | 第 0–13 tick（**0.467 s**），期间所有伤害与机制判定全部 miss |
| 位移 | 第 0–9 tick（0.333 s）内位移 **110 px** |
| 位移方向 | 垂直于「玩家 → 当前锁定目标」的连线，**左右交替**（第 1 次左、第 2 次右，计数器奇偶决定） |
| 冷却 | **36 tick（1.20 s）**，从 dodge 第 0 tick 起算 |
| 耐力 | 上限 100，单次消耗 30，回复 15/s（0.5/tick），闪避结束后 **12 tick（0.40 s）** 开始回复 |
| 打断 | dodge 可主动打断 attack 与 cast（打断 cast 返还 50% 资源，**不进 CD**）；dodge 不可打断 hurt / dead / 另一个 dodge |
| 受身 | 处于 hurt（硬直）时点击闪避 → 立即解除硬直并进入 dodge（消耗照常） |

**为什么位移是"侧向"而不是"后撤"**：Boss 的橙标机制（直线水龙卷、地面圆）需要玩家**横移**才能脱离判定区；后撤会顺着直线延长线走，等于躲不掉。侧向交替还能让玩家自动绕着敌人转圈，视觉上像"游斗"，弥补没有摇杆的单调。

**左右交替而非"远离威胁"**：固定交替 = 完全可预测 = 玩家能形成肌肉记忆；若按威胁方向动态计算，同一机制在不同角度会有不同结果，会造成"我明明按了却没躲开"的挫败。

### 3.6 误触与连点

| 情况 | 处理 |
| --- | --- |
| 同一技能狂点（CD 中，剩余 > 9 tick） | 只出"未就绪"反馈（灰 + 抖动 0.12s + 闷响），**不入队**。理由：自动连放会剥夺玩家对资源与节奏的控制，且会在 CD 结束瞬间把 3 个技能同时打空 |
| 同一技能狂点（CD 剩余 ≤ 9 tick） | 进入缓冲；**后一次点击覆盖前一次**，缓冲只保留 1 个指令。CD 归零立即释放 |
| 5 tick（0.167s）内点了两个不同技能 | 若前者已进入 cast（前摇 4–6 tick）→ **不打断**，后者丢弃并提示；若前者尚未进入 cast → 后者生效，前者取消 |
| 手指滑出按钮 | `pointerup` 位置若在按钮外 12px 以上，**不产生任何取消**（技能已按下即触发，不撤单）。理由：实时战斗中"撤销"比"误放"更致命 |
| `pointercancel`（来电 / 系统手势） | 清空该 pointerId，**不影响已触发的技能** |
| 连点间隔下限 | 无。不 debounce、不节流（与 `tech_baseline_v1.md` 5.7 的队列上限 3 一致） |

### 3.7 拇指可达区

右手持机，拇指根部枢轴取 **(370, 812)**（屏幕右下角内缩 20px）：

| 键 | 中心 | 到枢轴距离 | 频率 |
| --- | --- | --- | --- |
| 技能 B（主输出） | (336, 752) | 69 px | 最高 |
| 技能 C | (232, 794) | 139 px | 高 |
| 技能 A | (340, 648) | 167 px | 高 |
| 闪避 | (238, 698) | 174 px | 高 |
| 药瓶 | (262, 604) | 234 px | 低（每场 0–2 次） |
| 暂停 | (356, 40) | — | 极低（左手或换手） |

**结论**：高频 4 键全部落在 **69–174 px** 的舒适环内，拇指不需要伸展；唯一需要"上探"的是药瓶（低频救命键，允许 234 px）。全部 5 个战斗键构成一个右下角的弧形簇，拇指小幅摆动即可覆盖，不需要移动握持姿势。

### 3.8 为什么这样能做到"30–90 秒打完且不累"

1. **输出 100% 由系统承担**：普攻自动、寻敌自动、走位自动。玩家不需要维持任何持续操作，手指全程是"抬起—落下"的离散动作，而不是"按住不动"。
2. **操作密度经过配平**：一场杂兵战 16–25 秒，玩家只需 **7–17 次技能点击 + 2–4 次闪避**（§10）。平均每秒不到 1 次点击，且每次点击之间都有 ≥1.2s 的自然空档（技能 CD 下限 3.0s、闪避 CD 1.2s），肌肉不会持续紧张。
3. **所有操作都是"一次性点击"**：没有长按蓄力、没有滑动搓招、没有方向选择。技能目标是自动锁定的最近敌人，玩家不需要在慌乱中做"选目标"这类精细操作。
4. **反馈替代操作量**：爽感来自闪避擦身的 0.467s 无敌、暴击的屏幕轻震与放大数字、装备替换后的手感突变，而不是来自玩家的 APM。

## 4. 三职业设定

### 4.1 力士 —— 「怒气」

| 项 | 值 |
| --- | --- |
| 定位 | 近战坦克 / 爆发。站桩硬吃，越挨打越强 |
| 核心资源 | **怒气**，上限 100。生成：普攻命中 +8、受到伤害 +6、击杀 +20；脱战（5 s 内无攻击也无受击）后每秒 −5 |
| 初始属性 | HP 480 / ATK 26 / DEF 22 / 暴击 5% / 暴伤 150% / 攻速 100 / 移速 105 / 攻击距离 70 px |
| 专属机制 | **受击转化为输出**：怒气的主要来源之一是挨打，因此力士在敌群中越危险越强；技能池含 2 个护盾/减伤（铁壁、狂血）与最高的单体爆发系数（碎岳 600%） |
| 手感差异 | **一刀一顿、刀刀见血**——攻击间隔 1.1 秒，全职业最长，每次挥砍都有明显的蓄力与落地，技能是"攒满怒气后砸下去"的沉重爆发 |

### 4.2 术士 —— 「灵力」

| 项 | 值 |
| --- | --- |
| 定位 | 远程炮台 / 控场。距离即安全，蓝条即续航 |
| 核心资源 | **灵力**，上限 100。生成：恒定 9/s + 普攻命中 +5 + 击杀 +15；无脱战衰减 |
| 初始属性 | HP 380 / ATK 30 / DEF 13 / 暴击 8% / 暴伤 150% / 攻速 100 / 移速 110 / 攻击距离 265 px |
| 专属机制 | **265 px 超远攻击距离**——超过全部近战妖的接触范围，也超过 Boss1/Boss2 的机制半径（140 / 130），因此术士在部分橙标机制下天然更安全；代价是最低 HP 与 DEF。技能池以范围、持续、控制为主（灼符灼烧、冰封缓滞、雷引眩晕、万灵归一按敌人数倍率） |
| 手感差异 | **站着就能打，屏幕外先掉血**——弹道飞行让伤害有 0.6 秒的延迟抵达，安全但反馈滞后；靠技能密度而非普攻频率输出，蓝条见底时输出断崖 |

### 4.3 游侠 —— 「连击点」

| 项 | 值 |
| --- | --- |
| 定位 | 高频近中程 / 暴击流。最快的手，最脆的身 |
| 核心资源 | **连击点**，上限 5。生成：普攻命中 +0.40，暴击额外 +0.50；**8 s 内未获得新连击点则每秒 −1** |
| 初始属性 | HP 415 / ATK 26 / DEF 16 / 暴击 10% / 暴伤 150% / 攻速 100 / 移速 125 / 攻击距离 155 px |
| 专属机制 | **暴击驱动资源**：暴击额外产点，因此游侠的装备与技能会主动堆暴击（Lv10 裸暴击 21%）；连击点上限 5 且会衰减，逼迫玩家"产出即消耗"，不允许囤积。技能池是高频短 CD（影袭 3.0s / 落星 6.0s）与终结技（千刃 12 段） |
| 手感差异 | **像在打快板**——0.6 秒一刀，三倍于力士的频率，屏幕上伤害数字连绵不断；技能的段数（2/3/8/10/12 段）让单次点击炸出一串数字，是三职业中"最忙"也最爽的 |

### 4.4 三职业横向对照（Lv1 裸装 + 起始武器）

| | HP | ATK | DEF | 暴击 | 普攻间隔 | DPS(对 DEF=25) | Boss3 战承伤 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 力士 | 495 | 31.0 | 25.0 | 6% | 1.100 s | 61.1 | 67% |
| 术士 | 395 | 35.0 | 16.0 | 9% | 1.067 s | 48.1 | 75% |
| 游侠 | 430 | 31.0 | 19.0 | 11% | 0.600 s | 48.5 | 68% |

Lv1 术士/游侠 DPS 略低于力士是有意为之：力士必须贴脸（吃到全部近战伤害），术士/游侠用范围与频率补偿，并在 Lv6 后反超（游侠 Lv10 DPS 309.6 > 力士 286.2 > 术士 273.3）。

## 5. 参数终值表

### 5.1 属性定义与伤害结算公式

| 属性 | 字段 | 单位 | 说明 |
| --- | --- | --- | --- |
| 攻击 | `atk` | 点 | 所有伤害的唯一乘算基数 |
| 防御 | `def` | 点 | 走除数减伤，无上限、不封顶但收益递减 |
| 生命 | `hp` | 点 | 上限与当前值 |
| 暴击率 | `crit` | 0–0.75 | 上限硬封 75% |
| 暴伤 | `critDmg` | 倍率 | 基准 1.50，即暴击造成 150% 伤害 |
| 攻速 | `haste` | 百分比 | 100 = 基准；只影响普攻间隔与技能前摇，**不影响 CD** |
| 移速 | `speed` | px/s | 玩家自动移动速度 |
| 闪避冷却 | `dodgeCdTicks` | tick | 全职业统一 36 |
| 耐力 | `stamina` | 点 | 上限 100，闪避消耗 30，回复 15/s |

**伤害结算（可直接翻译为代码）**

```
// 输入：ATK（攻击方）、SKILL_COEF（技能/普攻系数）、FLAT（固定加成）
//      TARGET.DEF、ARMOR_PEN（0–1，护甲穿透）、ARMOR_REDUCE（0–1，缓滞降防）
//      DMG_AMP（伤害加成%之和）、DMG_REDUCE（伤害减免%之和）
//      CRIT、CRIT_DMG、rng()∈[0,1)

EFF_DEF   = max(0, TARGET.DEF * (1 - ARMOR_PEN) * (1 - ARMOR_REDUCE))
BASE      = ATK * SKILL_COEF + FLAT
MITI      = 100 / (100 + EFF_DEF)
AMPLIFY   = max(0.2, 1 + DMG_AMP - DMG_REDUCE)
CRIT_MUL  = (rng() < CRIT) ? CRIT_DMG : 1
VARIANCE  = 0.95 + 0.10 * rng()
RAW       = BASE * MITI * AMPLIFY * CRIT_MUL * VARIANCE

// 结算顺序
if (TARGET.SHIELD > 0) {
    absorbed = min(TARGET.SHIELD, RAW)
    TARGET.SHIELD -= absorbed
    RAW -= absorbed
}
TARGET.HP -= max(1, round(RAW))
FINAL = max(1, round(RAW_BEFORE_SHIELD))   // 飘字显示扣除护盾前的完整值
```

**攻击间隔**

```
INTERVAL_TICKS = max(6, round(BASE_INTERVAL_TICKS * 100 / (100 + HASTE)))
```

**减伤对照（MITI 速查）**：DEF 10→0.909、20→0.833、30→0.769、40→0.714、50→0.667、61→0.621、80→0.556。

## 7. 战斗状态机

### 7.1 状态定义

| 状态 | 进入条件 | 持续 | 期间行为 | 退出 |
| --- | --- | --- | --- | --- |
| **idle** | 无锁定目标，或目标距离 > 攻击距离 | — | 自动向目标移动（速度 = SPEED × (1−缓滞)） | 进入射程 → attack |
| **attack** | 距上次普攻 ≥ `INTERVAL_TICKS` 且目标在射程 | 前摇 6 t + 命中帧 + 后摇（合计 = `INTERVAL_TICKS`） | 不可操作；可被 dodge / hurt 打断 | 结束 → idle |
| **cast** | 玩家点击技能且裁决通过 | 前摇（见 §5.4）+ 后摇 6 t | 不可再释放其他技能；**前摇期间受击不打断** | 结束 → idle |
| **dodge** | 玩家点击闪避且耐力/CD 满足 | **17 t**（无敌 0–13 t，位移 0–9 t） | 不可攻击、不可施法；移动由闪避位移接管 | 结束 → idle |
| **hurt** | 单次伤害 ≥ 12% 最大生命，或被眩晕/定身 | **6 t（普通硬直）** / 眩晕剩余 tick（控制硬直） | 不可攻击、不可施法、不可闪避 | 结束 → idle；点闪避可**立即受身**解除普通硬直（控制硬直不可） |
| **dead** | HP ≤ 0 | — | 终止一切行为与输入 | 战斗结算 |

### 7.2 优先级与打断矩阵

优先级（高 → 低）：`dead > hurt > dodge > cast > attack > idle`

| 当前 ↓ / 试图 → | attack | cast | dodge | hurt | dead |
| --- | --- | --- | --- | --- | --- |
| **idle** | ✔ | ✔ | ✔ | ✔ | ✔ |
| **attack** | — | ✔ | ✔（打断，普攻重置） | ✔（打断） | ✔ |
| **cast** | ✘（普攻排队到 cast 结束后） | ✘（同技能 CD 中；5 t 内的异技能点击丢弃） | ✔（打断，返还 50% 资源，**不进 CD**） | ✔（打断，返还 100% 资源，**不进 CD**） | ✔ |
| **dodge** | ✘ | ✘ | ✘（CD 36 t 天然互斥） | ✔（仅眩晕/定身强制进入） | ✔ |
| **hurt** | ✘ | ✘ | ✔（仅普通硬直可受身；控制硬直不可） | — | ✔ |
| **dead** | ✘ | ✘ | ✘ | ✘ | — |

补充规则：
- 眩晕 / 定身使玩家强制进入 `hurt`，持续 = 异常剩余 tick，期间**不可受身**。
- `cast` 被 `dodge` 打断后，技能返还 50% 资源（向下取整），**不进入 CD**（防"躲一下就废一个技能"的惩罚感）。
- `cast` 被 `hurt` 打断（真实被打断）返还 100% 资源，不进 CD。
- 玩家在 `cast` 前摇期间受击**不打断**（只出受击反馈），只有达到 12% 最大生命的重击才进 `hurt`。

### 7.3 异常状态（4 种，唯一上限）

全作只有这 4 种异常，不允许增加第 5 种（新效果一律折叠进这 4 种的参数里）。

| # | 名称 | 字段 | 持续与结算 | 可叠层 |
| --- | --- | --- | --- | --- |
| 1 | **灼烧** BURN | `{ tickPerHit: 30, coef }` | 每满 30 tick 结算一次，伤害 = 施法者 ATK × coef，**不吃减伤**（跳过 MITI），可被护盾吸收；到期移除 | 否，后施加者**刷新时长**并取更高 coef |
| 2 | **眩晕** STUN | `{ ticks }` | 强制进入 `hurt`，禁止 attack / cast / dodge；逐 tick 递减 | 否，取更长剩余 |
| 3 | **缓滞** SLOW | `{ move: 0–1, atk: 0–1, def: 0–1 }` | 同时作用于三者：移速 ×(1−move)、攻击间隔 ÷(1−atk)、防御 ×(1−def)；逐 tick 递减 | 否，取三项各自的更大值 |
| 4 | **护盾** SHIELD | `{ value, ticks }` | 优先于生命被扣除；护盾破裂时触发来源的破盾效果（如灵盾 Lv3）；未破则到期清零 | 是，**数值相加**，时长取更长 |

> **"破甲"归属说明**：破甲不是第 5 种异常，而是 **缓滞的 `def` 分量**（猛击 Lv3 = 缓滞 `{move:0, atk:0, def:0.20}`）。同理"减速""降攻速""降防"三种需求共用缓滞一个槽位，避免状态系统膨胀。

### 7.4 每 tick 结算顺序（固定，不可调换）

```
1  资源再生（术士灵力 +9/s；耐力 +15/s；力士脱战衰减；游侠连击点衰减）
2  异常/Buff 计时递减；灼烧满 30 tick 则结算一次伤害
3  冷却递减（3 技能 / 闪避 / 药瓶）
4  输入缓冲裁决（CD 剩余 ≤ 9 tick 且已缓冲 → 归零即释放）
5  敌人 AI（接近 / 前摇 / 释放 / 机制预警推进）
6  玩家自动移动
7  状态机推进（idle / attack / cast / dodge / hurt 迁移）
8  弹道推进与命中检测
9  伤害结算（公式 §5.1）→ 护盾 → 生命 → 死亡判定
10 波次推进（本波全灭 → 36 tick 后下一波）
```

## 10. 节奏验算（用 §5.1 公式与 §5.2–5.6 的表手算/脚本核算）

**验算口径**
- 输出效率系数 **0.88**（闪避、受击硬直、机制规避造成的输出中断）
- 承伤规避系数 **0.77**（玩家主动闪避的无敌覆盖 + 远程职业天然少吃近战）
- 远程减伤额外系数：力士 1.00 / 术士 0.80 / 游侠 0.90
- 每波入场与接近 2.0 s；波间隔 1.2 s
- 代表配装：章一 = 猛击 Lv2 / 撼地 Lv1 / 铁壁 Lv1；章二 = 猛击 Lv3 / 旋风 Lv2 / 碎岳 Lv2；章三 = 猛击 Lv3 / 旋风 Lv3 / 碎岳 Lv3（术士、游侠按 §5.4 同章节位）

### 10.1 第一章杂兵战（C1-N1：纸人 ×3 → 纸人 ×2 + 骨雀 ×1）

**力士 Lv1**（HP 495 / ATK 31.0 / DEF 25.0 / 暴击 6% / 普攻间隔 33 t）

```
普攻 DPS   = 31.0 × 1.20 / 1.100                     = 33.8
猛击 Lv2   = 31.0 × 2.80 / 4.0 s                     = 21.7   （怒气供给 7.3/s ≥ 需求 6.25/s ✓）
原始合计                                              = 55.5
暴击期望   × (1 + 0.06 × 0.50)                       = 57.2
减伤       × 100/(100+6)                             = 53.9
效率       × 0.88                                     = 47.4
战斗时长   980 / 47.4 + 2波×2.0 + 1.2                = 20.6 s   ✓（目标 15–30）
承伤       ≈ 15% 最大生命
技能点击   猛击 20.6/4.0 + 撼地 20.6/8.0 + 铁壁 20.6/12 ≈ 9.5 次
           加闪避 2–3 次 → 全场约 12 次点击 / 20.6 s（每 1.7 s 一次）
```

| --- | --- | --- | --- |

| 术士 | **24.8 s** | 21% | 13.2 |
